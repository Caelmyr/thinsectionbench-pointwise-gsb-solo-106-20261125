# Thin Section Bench 岩片工作台

在已经归一到同一像素坐标的交偏光照片上记录视域、装片废区、人工点数和矿粒量测。交偏光原图可附同视域的偏光对照以及带载物台角度的一组照片。内置练习为程序合成的图像。

## 启动

在项目目录运行 `docker compose up --build -d`，打开 `http://127.0.0.1:19909/`。运行 `docker compose stop` 停止。记录和照片保存在命名卷中。可用 `THINBENCH_PORT` 指定其他本机端口。

也可在 Python 3.11 或 3.12 的虚拟环境安装 `requirements.txt` 后执行 `./start.sh`。本地启动读取 `HOST`、`PORT` 和 `THINBENCH_DATA`。

## 操作

1. 导入原图，或打开工作柜中的合成练习。支持单帧 PNG、JPEG、TIFF、BMP、WebP，每张不超过 22 MiB、6000 像素边长及 1200 万像素。
2. 在「观察」填写旋转视域并框出废区。回到原图可以查看视域、废区和引导点，也可下载裁正视域。
3. 在「点数」标注及修改人工判读。用「量测」设标尺、测线，或圈出矿粒以查看面积、长短方向和方向图。
4. 在「图像分析」读取亮度分布、剖面、测带边界、阈值连通、清晰度、纹理、矿粒内部以及同视域偏光变化。灰度与色彩读数来自解码后的图像，按各分析的选区条件处理。
5. 从「工作与导出」保存一版标注，下载图片、CSV 或可重开的观察包，也可把原图复制进照片准备工作区。准备工程数据独立存储，可把准备结果导出为新图，再从工作柜导入。

标尺只用于由该张原图坐标换算距离和面积。角度序列读数对应实际提供的照片。使用偏光差异读数前，请在拍摄或准备阶段保证两张图在同一坐标中。

若横、纵每像素的物理尺寸不同，可在「量测」切到「横纵分别标定」，沿用原图记 2–4 段标尺的两端和各自实长，并给出可接受的实长误差。系统用平方长度最小二乘枚举可分开横纵方向的标尺组合，优先选落在误差内段数最多、长尺加权偏差最小的一组，逐段列出预测偏差；仅正负镜像的两条斜线属于同一方向族，不能分开横纵比例。没有至少两段落在误差内时保留原单标尺模式。保存后测线实长、亮度剖面（可按微米间隔采样，末端不足一个间隔也会保留终点）、剖面 CSV、矿粒面积和测带读数均按横纵比例计算，剖面图与 CSV 共用同一套实距离和原图采样位置。
